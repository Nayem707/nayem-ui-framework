# Compatibility

Supported React versions, peer dependencies, and browser requirements for Lumynar UI.

---

## React version support

| React version | Support | Notes |
|---------------|---------|-------|
| **19.x** | Supported | Primary test target |
| **18.x** | Supported | Tested |
| **17.x** | Supported | Should work without changes |
| **16.8 – 16.x** | Supported | Minimum practical version — hooks required |
| **16.0 – 16.7** | Not supported | Components use `useState` and `useEffect` |
| **15.x** | Not supported | Listed in peer deps but incompatible with current source |

> **Warning:** The `package.json` peer dependency declares `react >= 15.0.0`. In practice, **React 16.8+** is required. Do not rely on React 15 compatibility.

---

## Why React 16.8+ is required

Several exported components use React hooks:

| Component | Hooks used |
|-----------|------------|
| `Toast` | `useEffect` |
| Internal utilities | `useState`, `useEffect` |

There is a `reactCompat.js` utility layer in source, but it is **not used** by individual components today.

---

## Peer dependencies

```json
{
  "peerDependencies": {
    "react": ">=15.0.0",
    "react-dom": ">=15.0.0"
  }
}
```

Your application must install compatible versions of both packages.

---

## Installation by React version

### React 18 or 19

```bash
npm install lumynar-ui
```

### React 17

```bash
npm install lumynar-ui
```

### React 16.8+

```bash
npm install lumynar-ui
```

### Peer dependency warnings

```bash
npm install lumynar-ui --legacy-peer-deps
```

---

## Module formats

| Format | File | Import style |
|--------|------|--------------|
| CommonJS | `dist/index.cjs.js` | `require('lumynar-ui')` |
| ES Module | `dist/index.esm.js` | `import { Button } from 'lumynar-ui'` |

Both formats are generated by Rollup. React and React DOM are externalized and not bundled.

---

## Tailwind CSS compatibility

| Tailwind version | Status |
|----------------|--------|
| v3.x | Supported (recommended) |
| v4.x | Not tested — may work with adjusted content paths |

Components do not ship CSS. Tailwind must be configured in the consumer application.

---

## Browser support

Lumynar UI targets modern browsers supported by React 18+:

- Chrome (last 2 versions)
- Firefox (last 2 versions)
- Safari (last 2 versions)
- Edge (last 2 versions)

IE11 is not supported.

---

## TypeScript

TypeScript definitions (`.d.ts`) are **not yet available**. They are planned for v0.2.

Until then, TypeScript projects can use the package with a module declaration:

```ts
// lumynar-ui.d.ts
declare module 'lumynar-ui' {
  import { ComponentType, ReactNode, CSSProperties, FormEvent } from 'react';

  export const Button: ComponentType<{
    children?: ReactNode;
    label?: string;
    variant?: 'primary' | 'secondary' | 'danger';
    size?: 'sm' | 'md' | 'lg';
    disabled?: boolean;
    className?: string;
    style?: CSSProperties;
    onClick?: () => void;
  }>;

  // Add other components as needed
}
```

---

## Compatibility checklist

Before adopting Lumynar UI in a project, verify:

- [ ] React 16.8 or higher installed
- [ ] Tailwind CSS configured with `node_modules/lumynar-ui/dist/**` in content paths
- [ ] Global CSS includes `@tailwind` directives
- [ ] Components imported from `'lumynar-ui'` (not internal paths)
